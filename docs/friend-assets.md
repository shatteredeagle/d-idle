## Freepik replacement in the private fork (APPLIED 2026-11-11, commit a392bcbd on fork-only/icon-original, off c418e235)

Steps as done (kept for the next icon change):

1. Branch `fork-only/icon-original` off c418e235 (the framefeed/nocursor lineage), never in an upstream PR branch.
2. Replace `assets/icon/d2d.bmp` (64x64, BMP4 with alpha, the format `SDL_LoadBMP_IO` reads) with the original pixel-art icon from the branding task; replace `d2d.png`, `d2d.ico`, and the `d2d.svg` master the same way (the svg may be a simple pixel-rect svg).
3. In `assets/icon/README.md` and `LEGAL.md` drop the dgim-studio/Freepik sentence for the files replaced; keep the AvQest/Freepik lines for the launcher files that remain.
4. `cmake -S . -B build` re-bakes the bmp; check with `strings` that "Freepik" no longer appears in the binary and run one boot.
5. Commit, push to the private forge remote the same day, give the new commit to the pack build (`--d2d-commit`). After that `build.sh` writes no Freepik line, and checklist item 3 fails if the tree and the notice disagree.

Notices text while the icon is still Freepik: `The d2d window icon (goat skull and pentagram) is "Designed by dgim-studio / Freepik", used under the Freepik licence.` (already emitted by `build.sh`).
