# Live check of the watch panels against real lockstep runs (panelslive)

> status: measured 2026-11-08 (EST). Tags: V verified live (how stated), S code reading, U unverified. Evidence is a poller (`docs/probes/panelslive/poll.sh`) that saved every GET api every 6 wall seconds (about 2 virtual minutes) while `d2bot play` ran; tokens are never copied here.

## Method (V)
Two fresh characters through the normal path, lockstep d2d (lab verbs OFF, no `d2cheat`, no memory write: writes after start 0), `docs/probes/panelslive/run-live.sh TAG CLASS SEED 3m` with `POLL=6` (viewer on loopback of a lab slot, nice 19, one run at a time on the worker host):
- `pal1`: Paladin (`paladin-normal30-v2`), seed 7, 29 polls, about 45 virtual minutes, clvl 5 (Blood Moor, Den of Evil cleared, Cold Plains).
- `sor1`: Sorceress (`sorceress_normal30`), seed 7, 29 polls, about 50 virtual minutes, clvl 4 (Blood Moor, Den, Burial Grounds). The poller bought the `alerts` unlock once the tally held 60 (a normal player action on the answer port, not a game write) to see an alert fire.
The page itself was NOT opened in a browser (U); only the JSON.
