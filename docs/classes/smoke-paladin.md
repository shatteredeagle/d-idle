# Paladin smoke test (agent CLASSPAL, 2026-10-28)

Report-only run of the current Sorceress bot's building blocks on a throwaway softcore Paladin ("Palli", instance i1, Normal, 1.14d). No shared package was edited. Probe tool: `tools/rigs/classsmoke` (`state`, `stl`, `chain`, `aurakey`, `melee`, `cheat`, `tree`, raw `click/key/hold`); everything else used `combatlive`, `levelerlive`, `oog`. Tags: **V** observed live (how stated), **U** not verified (code reading or not run).

Cheats (ledger actor `classpal`, all on Palli, offline, with reasons): save edits to clvl 6, then clvl 13 with skills Sacrifice 5, Smite 3, Might 1, Holy Fire 5, Holy Bolt 3, Zeal 3 and Str 60 (so the combat code had real Paladin skills); one life-to-2 memory write for the death test. `tools/rigs/classsmoke` appends "Palli" to `cheat.Allowed` at run time (in that tool only), because `cmd/d2cheat` would refuse her (finding 12).

## What the bot needs for a Paladin to play unattended

1. **Class profile (combat, BLOCK 1+2):** data per class: left skill, right skill (aura), ordered attacks per level band, buffs/auras, hotkey map, ranges. Paladin v1: left Zeal (Sacrifice before clvl 12, Smite as a fallback), right Holy Fire (Might first, later Concentration/Vigor), Holy Shield when learned. Attack with the left hand, never rebind the right.
2. **Left-skill binder and hand check (combat/bind.go):** left popup geometry above, verified through `LeftSkill`; after every respawn/area change read `LeftSkill`/`RightSkill` and the aura chain, fix what drifted.
3. **Aura reader (d2):** `Player.Auras` via the StatList child chain (finding 6); switching by hotkey costs 0.2 s and no mana.
4. **Melee engine (combat + input):** approach to 2-3 subtiles, left click or held left button for Zeal, no kiting, life-based retreat, retreat to the town on Sacrifice self damage; recheck Holy Bolt as a left missile.
5. **Paladin builds (leveler/plandata/bot config):** Might/Sacrifice/Holy Fire/Smite/Zeal rows with Strength and Dexterity (Strength 60 was enough for the test gear), skill-ownership validation and a learned-skill proof; Hammerdin after clvl 24 once the left-skill machinery exists.
6. **Gear and swap (leveler, town, d2):** melee weights, shield-aware weapon choice, active weapon set read, rebuy that never buys a 2h over a shield.
7. **Merc and chores (town, resource):** hire at Kashya/Greiz, revive after death; belt plan is already class-aware (hp hp hp mp).
8. **Infra:** cheat allow-list and sentinel character map per instance, so a second class can be created, restarted and cheated without code edits.

Order of work: 1 -> 2 -> 3 (a Paladin can then kill), 5 (it can level), 4 (it kills well), 6, 7, 8.
