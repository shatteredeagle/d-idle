Report-only run of the current bot (data-driven class model, master 997ebc5) on a throwaway softcore Amazon ("Amma", instance i3, Normal, 1.14d). No shared package was edited. Tags: **V** observed live (how stated), **U** not verified (code reading or not run). Severity: **BLOCK** = an Amazon cannot play unattended without it; **KNOB** = needs a profile/data/knob change; **COSM** = cosmetic.

Cheats (ledger actor `classama`, only on Amma, offline, with reason): one save edit at clvl 1 -> clvl 20, gold 4000, str 30 dex 45 vit 60, skills Magic Arrow 6, Fire Arrow 6, Inner Sight 1, Critical Strike 1, Jab 3, Multiple Shot 3, Dodge 1, Power Strike 1, Poison Javelin 3, Avoid 1, Lightning Bolt 3, Charged Strike 2, Valkyrie 1 (Valkyrie needs clvl 30 in skills.txt: memory/hotkey test only). ## What the bot needs for an Amazon to play unattended (8 steps)

1. **Weapon and ammo model (d2 + data):** `Item.Quantity` (stat 70), `Inventory.Ammo()` (quiver in body 5), equipped weapon class (bow, crossbow, javelin/spear), bow damage from the right columns or item stats 23/24 (findings 1, 3).
2. **Gear rules for a ranged class (leveler, town):** Amazon prefs (`bow`/`jave` bonus, no shield over the quiver, `miss` weapons allowed), rebuy a bow and the right ammo (Arrows for bows, Bolts for crossbows) when poor, `ShopTabs` page 2 (findings 1, 5, 12).
3. **Skill-weapon compatibility (combat):** `skills.json` `weapon` field, drop red skills before picking, no-effect detector so a no-op cast loop ends in seconds, with its own ignore reason (finding 2, 8).
4. **Ammo chores (town, resource, combat):** restock at Charsi's Misc tab when low (belt-like plan: bow Amazon 1 stack + 1 spare, javelin Amazon 2 stacks), an `AmmoLow` safety action that portals out, repair (findings 3, 10).
5. **Mana plan (combat, resource):** free Magic Arrow as the base attack, Multiple Shot/Fire Arrow above a mana line, no pack rest for free ladders, Valkyrie cast only when no owned class-357 unit is alive, Inner Sight on elites only (findings 7, 9).
6. **Leveling data (leveler, plandata):** bow build (Magic Arrow, Fire Arrow, Multiple Shot, Exploding Arrow, Strength for the bow) and a javelin build, with prerequisites from skills.txt (all V in `ama tree`), skill-ownership proof (finding 5).
7. **Mercenary (town, combat):** Kashya dialog entry, row picker by the on-screen type text, friendly filter for hireling classes (271, 338, 359) and revive; fix the target filter first because it is a bug for every class (findings 4, 6).
8. **Infra and verification (cheat, sentinel, tools):** allow-list from config, sentinel character per instance, `levelerlive tree` and `classsmoke tree` by class, then a live death run on a bow character (finding 11) and a javelin throw run (finding 10).

Order of work: 4 (merc filter) -> 3 (no-op casts) -> 1 -> 2 (she can fight with a bow) -> 6 (levels) -> 5 -> 7 -> 8.

## Notes and dead ends

- Gear the Amazon starts with is a Javelin stack, so a fresh Amazon plays as a melee/javelin character until the bot buys a bow: its first purchases (bow, quiver) are class-specific and must not wait for the leveler's score.
- Quiver and shield share the left-hand slot (body 5); the Buckler had to go to the pack. `town/rebuy.go` `slotFilled` would call the shield slot filled by the quiver, which is right.
- `townlive talk` waits take SECONDS (`w:2`), not milliseconds; `w:2000` hangs for the whole job limit.
- Every `live.sh` run takes the instance lock, so raw input (`classsmoke seq`) cannot run while a background job holds i3: hold a panel open from inside the job (`ama buy ... HOLD`, `townlive hold=S`) when a screenshot is needed.
- `levelerlive opentrade` closes the vendor before a screenshot can be taken; `ama buy NPC TABX TABY GX GY H HOLD` holds it open.
- Not verified: throwing weapon recovery, Strafe (hold), Exploding/Immolation Arrow, Slow Missiles, Decoy, Lightning Fury, Pierce/Critical Strike effects, weapon swap, Cold Arrow vs Fire Arrow Rogue effect, merc revive, repair of bows, window sizes other than 800x600, an actual death.
- Raw files: `ama/*.png` in the session scratchpad; the worker host `~/d2lod-live/classama/` (binaries, cache, runs).
