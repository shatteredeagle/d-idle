d.idle watch UI mockups

Static mockups of docs/ui-design-system.md. No scripts, no requests; each file carries the tokens, shell and components inline. Resize the window on the wide mockup: the shell goes 4 / 3 / 2 / 1 columns at 1440 / 1024 / 640 px by container query; the phone file shows the same markup in a 390 px frame with the Hero tab active.

  • 1watch-wide.html the main screen at any width (resize it)
  • 2watch-phone.html the main screen in a 390 px phone frame
  • 3inventory.html paper doll, backpack, belt, stash, repair, requests, upgrades
  • 4policy.html rows, locked options, preview card
  • 5return.html while you were away
  • 6overlay.html the stream overlay band (1920 by 160)
  • 7tokens.html the style guide: colour roles with contrast ratios, type, scales, component gallery
  • 8editor.html the draggable layout editor: drag and resize the real panels on a 12-column grid per viewport, presets, undo, export/import of the layout manifest (watch.layout/1). Renders: wide, 1440, phone viewport, command centre preset, live preset, light
