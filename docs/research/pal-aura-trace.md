## 1. Aura Target Filter (`FUN_0056b3e0`) and Area Search (`FUN_0056b740` / `FUN_0056b7e0`)

### 1.1 Self Application vs Area Search (`FUN_0056b740` and `FUN_0056b7e0`) (`V read + self-check`)

Every Paladin aura do-function splits application into two steps:
1. **Self (`FUN_0056b740` at `0x56b740..0x56b763`):** Takes `ecx = game`, `edx = caster`, `[esp+4] = callback`, `[esp+8] = ctx_arg`. If `caster != NULL`, it immediately invokes `callback(ecx = ctx_arg, edx = caster)` on the caster alone (`V read`).
2. **Area (`FUN_0056b7e0` at `0x56b7e0..0x56b9be`):** Takes `ecx = game`, `edx = caster`, `[esp+4] = x`, `[esp+8] = y`, `[esp+0x0c] = radius`, `[esp+0x10] = aurafilter`, `[esp+0x14] = callback`, `[esp+0x18] = ctx_arg`, `[esp+0x1c] = check_noaura`, `[esp+0x20] = file`, `[esp+0x24] = line` (`V read`).

Step-by-step execution of `FUN_0056b7e0` (`V read + self-check`):

## 5. Limits (`U`) and Reproducibility

### 5.1 What Was Not Verified (`U`)

1. **Live `d2d` / live `Game.exe` window execution (`U`):** Per the contributor rulebook (`docs/contributing/agent-work.md`), this trace was performed offline using `Game.exe` 1.14d under the Unicorn x86 emulator and static inspection of `d2d` (`6935cf6`). The live `d2d` probes in Sections 1.5, 2.6, and 3.5 were not run on a live `d2d` instance (maintainer-only).
2. **Corpse eating in Redemption (`124`, `srvdofunc` 82 `FUN_005d0e90`):** Redemption's `aurafilter` (`0x01102`) was decoded and verified in `FUN_0056b3e0` (`Suite 1`), and `FUN_005d0e90` / `FUN_005d0d70` were disassembled (`V read`), but its corpse conversion chance and life/mana return roll were not run in the `100,000`-case suites because the narrowed issue scope specified friendly auras, Holy Fire/Freeze/Shock enemy pulses, and Prayer mana / state 85.
3. **Thorns (`103`) and Sanctuary (`119`) knockback path:** Sanctuary's magic pulse damage (`EType = 3`) and `auratargetstate = -1` stat skip were verified in `Suite 2` (`V read + self-check`), while the knockback distance trajectory (`ResultFlags` bit `0x08` in `FUN_0057cee0`) and Thorns on-struck reflection (`ItemEvents.txt`) were outside scope (`U`).
