## 0. Method and a trap in our tooling

- Game data read with `mpq-cat` (`~/d2d-lab/src/build/tools/mpq-cat/mpq-cat`) on our own MPQ copy in `~/d2d-lab/data`, tables `data\global\excel\{monstats,levels,monlvl,hireling,charstats,difficultylevels,superuniques}.txt`. Extracted to a scratch dir, not copied into the repo. VERIFIED.
- TRAP: `mpq-cat` looks for `patch_d2.mpq` in lowercase, our copy is `Patch_D2.mpq`, so without a lowercase symlink it silently serves the OLD 1.10 tables (e.g. Andariel `MinHP 666`, no `hcIdx` column). I used a temp dir with lowercase symlinks; the real 1.14d patched tables have an `hcIdx` column and Andariel `minHP 2562`. Anyone re-reading data with that tool must do the same. VERIFIED (I hit it).
- The Normal HP rule (this settles claim 1): the table `minHP/maxHP` is NOT the in-game Normal HP. In-game HP = `minHP * monlvl.txt L-HP[monster level] / 100` also in Normal (column `L-HP`, Normal; `L-HP(N)`, `L-HP(H)` for the other two). Two anchors where I have an independent number: Andariel 2562 * 40/100 = 1024 and the Blizzard Classic Battle.net bestiary page (https://classic.battle.net/diablo2exp/monsters/act1-andariel.shtml, fetched 2026-10-30) says Andariel Normal hit points 1024, melee 6-19 (table 76-238 * `DM` 8/100 = 6-19, also matches), NM 24800, Hell 60031. Blood Raven 323 * 35/100 = 113 = the wiki number. VERIFIED (data and the Blizzard page); Blood Raven's 113 itself is SECONDARY (RankedBoost snippet, Diablo Wiki per `docs/sme/blood-raven-caster.md`).
- D2MOO (ThePhrozenKeep/D2MOO): I listed the repo tree through the GitHub API (`/git/trees/master?recursive=1`); the only merc-related path is a test fixture `HirelingTxtFixture.h`, so D2MOO has no hire or revive price code to read. VERIFIED (absence). Our `docs/research/d2moo-fit.md` is right that ITEMS price code lives elsewhere, but it does not help for mercs.
