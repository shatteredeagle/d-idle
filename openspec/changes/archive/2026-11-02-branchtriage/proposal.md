# branchtriage

## Why

Fifteen local agent branches are not contained in main and nobody knows which hold finished work, which were replaced and which must never be merged. A single table with a verdict and the exact command per branch lets the coordinator clean up without re-reading each card.

## What Changes

Adds docs/research/branch-triage-20261102.md, a read-only triage with the evidence per branch. No branch is merged, deleted or pushed by this card.
